KIMMIE BLACK & GOLD 3D WEBSITE

All website files and photos are in this ONE folder. Do not upload the ZIP directly to GitHub; unzip it and upload all files from inside.

1. Open index.html using VS Code Live Server (requires internet for the Three.js 3D library and Google Fonts).
2. Both 3D showrooms work immediately with CUSTOM CONCEPT car models. These are not official licensed 3D Mercedes-AMG or BMW models.
3. To use authentic licensed models, obtain rights to suitable .glb files and put them in this same folder, named exactly g63.glb and m5cs.glb. The website will automatically load them in place of the concepts. Model sizing/orientation may need adjustment depending on the file.
4. Music: if you have permission to use the audio, place a file named ungenzani.mp3 in the same folder. The website does not include the copyrighted song. Music starts only when the visitor clicks PLAY SONG.
5. Uploading a website to GitHub Pages makes the published site public even if the repository is private on some plans. A JavaScript password prompt is NOT real security. Use a hosting platform with server-side access controls before sharing private photos.
6. The photo gallery uses 5 supplied images; review them before publishing.
7. For best performance, use a modern browser with WebGL enabled and an internet connection.
